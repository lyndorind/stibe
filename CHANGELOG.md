# Changelog

Усі суттєві зміни проєкту STIBE REST API
задокументовано в цьому файлі.

Проєкт використовує семантичне версіонування
(Semantic Versioning).

## [Unreleased]

## [0.1.0] - 2026-11-27

### Added

- Створено REST-сервіс на Python із FastAPI.
- Реалізовано GET endpoint /.
- Реалізовано GET endpoint /health.
- Реалізовано GET endpoint /info.
- Додано документацію README.md.
- Налаштовано пакетний менеджер uv.
- Створено файл .gitignore.
- Налаштовано автоматизовану збірку Python-пакету в GitHub Actions.
- Реалізовано генерацію та перевірку контрольних хеш-сум SHA-256.
- Додано автоматизацію створення Git-тегів та GitHub Release.

### Changed

- Покращено відповідь головного endpoint /.
- Додано інформацію про версію сервісу
  до endpoint /info.
- Налаштовано єдине джерело версії Python-пакету та REST API.
