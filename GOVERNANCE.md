# Управління проєктом

## Ролі учасників

Адміністратор керує налаштуваннями репозиторію,
правами доступу та правилами захисту гілок.

Колаборатори вносять зміни, створюють
Pull Request та проводять рев'ю.

## Прийняття рішень

Усі зміни до головної гілки main вносяться
через Pull Request.

Для злиття необхідне щонайменше одне
схвалення від іншого учасника.

Усі зауваження рев'ю повинні бути вирішені
перед злиттям змін.

Основні пропозиції щодо розвитку проєкту
обговорюються в Issues.
