
# STIBE REST API

Простий REST-сервіс, розроблений на Python з використанням FastAPI
у межах лабораторних робіт з основ безперервної інтеграції.

## Технології

- Python 3.14
- FastAPI
- Uvicorn
- uv

## Встановлення залежностей

```bash
uv sync
```

## Запуск сервісу

```bash
uv run stibe
```

Сервіс доступний за адресою http://127.0.0.1:8000.

## Endpoint

| Метод | Шлях | Опис |
|-------|------|------|
| GET | / | Інформація про роботу сервісу |
| GET | /health | Перевірка працездатності сервісу |

## Документація API

Swagger UI: http://127.0.0.1:8000/docs
