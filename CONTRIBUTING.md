# Правила внесення змін

## Підготовка середовища

Для роботи з проєктом необхідні Python 3.14, Git та uv.

Для встановлення залежностей виконайте:

    uv sync

Для запуску REST-сервісу виконайте:

    uv run stibe

## Порядок внесення змін

1. Створіть окрему feature-гілку.
2. Внесіть необхідні зміни.
3. Перевірте працездатність REST-сервісу.
4. Створіть підписаний коміт.
5. Завантажте гілку на GitHub.
6. Створіть Pull Request та запросіть рев'ю.

## Вимоги до змін

- Дотримуйтеся стандарту PEP 8.
- Використовуйте зрозумілі повідомлення комітів.
- Оновлюйте документацію за необхідності.
- Не додавайте паролі та приватні ключі.
- Вносьте зміни до main лише через Pull Request.
